## Selected Projects

### [urlfckr](https://github.com/estebanzarate/urlfckr)

A Python web crawler I built to practice web reconnaissance and multithreading.

* Subdomain and path discovery
* Recursive crawling
* Concurrent requests
* Rate limiting
* Custom HTTP headers
* JSON export

**Python · Requests · BeautifulSoup · Multithreading**

---

### [HTBash](https://github.com/estebanzarate/htbash)

A Bash project I built to practice working with the Hack The Box API.

* Synchronizes Hack The Box machine information
* Filters machines by OS, difficulty and ownership
* Uses local JSON caching
* Provides a command-line interface

**Bash · curl · jq · REST API**

---

### [Fullstack App](https://github.com/estebanzarate/fs)

A practice project exploring the architecture and security considerations of a modern full-stack application.

* React + TypeScript frontend
* Node.js + Express backend
* PostgreSQL database
* JWT authentication with rotating refresh tokens
* httpOnly cookies
* Role-Based Access Control
* Transactions and soft deletes
* Docker-based local development

**React · TypeScript · Node.js · Express · PostgreSQL · Docker**
